# Analog Control II — University of Kufa

Student-facing lecture website for **Analog Control II**, Fourth Grade, Electrical Engineering Department.

**Instructor:** Assistant Prof. Dr. Ali Al-Ghanimi

## Course website source
The public student site lives in the `site/` folder.

Published pages currently included:
- `site/index.html` — course home
- `site/syllabus.html` — syllabus
- `site/week02.html` — Week 2: Root Locus Foundations

## References
- Norman S. Nise, *Control Systems Engineering*, 6th Edition — primary lecture reference.
- B. C. Kuo, *Automatic Control Systems* — selected supporting problems.
