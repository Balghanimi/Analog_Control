Root Locus Foundations

See how closed-loop poles move when gain changes

Start from the feedback system, derive the characteristic equation, understand angle and magnitude conditions, then construct the general root-locus shape using Nise's five basic rules.

1. From the feedback diagram to Root Locus

T(s) = K G(s)1 + K G(s) H(s)

The closed-loop poles are obtained from the denominator:

1 + K G(s) H(s) = 0
K G(s) H(s) = −1
Root locus is the path of the closed-loop poles in the s-plane as K varies from zero toward infinity.
Nise §8.3 derives root-locus properties from this standard negative-feedback characteristic equation.

4. Nise's five basic sketching rules

1 · Branches
Number of branches equals the number of open-loop poles.
2 · Symmetry
The root locus is symmetric about the real axis.
3 · Real-axis segments
For K > 0, a real-axis point belongs to the locus if the number of finite real poles and zeros to its right is odd.
4 · Start / end
Branches begin at open-loop poles and end at open-loop zeros, including zeros at infinity.
5 · Asymptotes
When n > m, n−m branches go to infinity.
Centroid & angles
σₐ = Σp − Σzn − m
θₐ = (2k + 1)180°n − m
Nise §8.4.

6. MATLAB verification

Use MATLAB after the hand analysis:

s = tf('s'); G = 1/((s+2)*(s+4)*(s+6)); figure; rlocus(G); grid on; title('Root Locus — Week 2');
Engineering habit: if MATLAB disagrees with your hand sketch, identify which rule you applied incorrectly rather than copying the plot blindly.
